# KEC数学科ラボ

小学生・中学生向けの算数・数学学習アプリを一覧から選んで利用できる、共通ポータルサイトです。
HTML / CSS / JavaScript のみで構成された静的サイトで、GitHub Pages でそのまま公開できます。

## 1. サイトの概要

- タイトル：**KEC数学科ラボ**
- 対象：小学4年生〜中学3年生
- 生徒がアプリを選び、ボタンを押すとすぐにそのアプリのトレーニングを始められる「ゲームの選択画面」のようなポータルです。
- 小学生向けアプリ、中学生向けアプリのセクションに分かれて表示されます。

## 4. 新しいアプリを追加する方法（プログラミングに詳しくない方向け）

新しいアプリを追加するときは、`script.js` というファイルだけを編集します。HTMLは触らなくて大丈夫です。

1. `script.js` をテキストエディタで開きます。
2. ファイルの上のほうにある `const apps = [ ... ];` という部分を探します。
   ここにアプリの情報が、`{ }` で囲まれたブロックとして1つずつ並んでいます。
3. 一番最後のアプリのブロック（`}` で終わっている部分）の直後に、カンマ `,` を入れてから、新しいアプリの情報を同じ形式でコピー＆貼り付けし、内容を書き換えます。

追加する情報の例：

```javascript
{
  id: "new-app-id",                 // 半角英数字とハイフンで、他のアプリと重ならない名前
  category: "elementary",           // "elementary"=小学生向け, "juniorhigh"=中学生向け
  title: "新しいアプリの名前",
  subtitle: "",                     // サブタイトルがなければ空文字のままでOK
  grades: "小学5年生・小学6年生",
  catchphrase: "キャッチコピーをここに",
  description: "生徒向けの説明文をここに書きます。",
  tags: ["タグ1", "タグ2", "タグ3"], // 個数は自由に増減できます
  icon: "🎲",                       // 絵文字を1つ設定
  url: "https://example.github.io/new-app/",
  theme: "space",                   // カードの色テーマ（下記4-1を参照）
},
```

入力できたらファイルを保存するだけで、ページを開いたときに自動でカードが追加されます。HTMLファイルを直接編集する必要はありません。

### 4-1. 色テーマ（アクセントカラー）について

`theme` に指定できる名前と、対応する色は `style.css` の「アプリごとのテーマカラー」という部分にまとめてあります。

- `space`（青・水色）
- `wordproblem`（緑・黄緑）
- `puzzle`（黄色・青緑）
- `primeattack`（紺）
- `nazoten`（青紫・シアン）
- `factorization`（赤・オレンジ）
- `linear`（紫・青紫）
- `labyrinth`（紺・金）

新しい色を使いたい場合は、`style.css` に次のような形式を追加し、`script.js` 側の `theme` にその名前を指定してください。

```css
.app-card[data-theme="新しいテーマ名"] {
  --accent-1: #メインカラー;
  --accent-2: #サブカラー;
}
```

### 4-2. 新しい区分（カテゴリ）を追加したい場合

現在は「小学生向け（elementary）」「中学生向け（juniorhigh）」の2区分です。
「小中学生共通」「講師向け」「新着アプリ」「開発中アプリ」などを追加したい場合は、

1. `index.html` に新しいセクション（見出し・説明文・カードを入れる空の枠）を追加する
2. `script.js` の `CATEGORY_CONTAINER_IDS` に、その区分名と枠のidの対応を追加する

という2つの作業が必要です。区分を増やす際は、詳しい方に依頼してください。

## 5. アプリ情報を変更する方法

アプリ名・対象学年・説明文・タグ・URLなどを変更したいときも、`script.js` の該当するアプリのブロックの中身を書き換えるだけです。他のアプリの情報には影響しません。

## 6. GitHub Pages で公開できる静的サイトであること

このサイトは HTML / CSS / JavaScript のみで動作し、ビルドやサーバー処理を必要としません。
リポジトリを GitHub にアップロードし、GitHub Pages を有効にするだけでそのまま公開できます。

- npm などによるビルドは不要です
- サーバーサイド処理・データベース・外部APIは使用していません

## 7. ローカルで確認する方法

このフォルダの `index.html` を、そのままブラウザで開くだけで表示を確認できます。

より実際の公開環境に近い状態で確認したい場合は、このフォルダ内で以下のいずれかを実行し、表示されたURL（例：`http://localhost:8000`）にアクセスしてください。

```bash
# Python がインストールされている場合
python -m http.server 8000
```

```bash
# Node.js がインストールされている場合
npx serve .
```

## 8. リンクは同じタブで開く仕様であること

各アプリの「ゲームをはじめる」ボタンは、通常の `<a href="...">` リンクとして実装しており、`target="_blank"` や `window.open()` は使用していません。ボタンを押すと、ポータルサイトを表示している現在のタブが、そのままアプリのページに切り替わります。新しいタブやウィンドウは開きません。
